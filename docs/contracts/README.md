# Contracts

These documents describe current observable behavior. Changes to the installer
or managed configuration should update the corresponding contract.

- [Installer](installer.md): modes, side effects, backups, drift detection,
  environment handling, and the preserving mode.
- [Configuration](configuration.md): source/destination paths, shell commands,
  editor sharing, and platform boundaries.

For procedures, use [operations](../operations/README.md). For the structure
behind these behaviors, use [architecture](../architecture/README.md).
