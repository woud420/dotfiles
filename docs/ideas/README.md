# Ideas

Use this folder for unimplemented proposals, experiments, and future directions.
There are no active proposal documents here yet; historical convergence
exploration is linked from the [accepted decision](../decisions/machine-convergence.md).

A proposal should state the problem, intended behavior, alternatives, open
questions, and how it could be validated. Give it a descriptive topic name and
put its lifecycle status inside the document.

When resolved, move it into [decisions](../decisions/README.md), rewrite it as the
outcome, and update incoming links. Current guarantees belong in contracts and
repeatable procedures belong in operations.
