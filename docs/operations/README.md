# Operations

Use these guides for repeatable work, with commands run from the repository root
unless stated otherwise.

- [Installation](installation.md): prerequisites, mode selection, platform setup,
  and first verification.
- [Customization](customization.md): local overrides, Git hooks, editor settings,
  and terminal themes.
- [Private skills](private-skills.md): authenticated initialization, destination
  selection, and intentional revision updates.
- [Maintenance and recovery](maintenance.md): drift, dependency checks, backups,
  manual restore, and plugin updates.
- [Validation](validation.md): repository checks, temporary-home coverage, editor
  parity, and CI scope.
- [Arch desktop](arch-desktop.md): SwayFX, Waybar, Firefox, packages, and reloads.

For exact mode behavior and installed paths, use [contracts](../contracts/README.md).
