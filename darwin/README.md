# macOS configuration

[`Brewfile`](Brewfile) defines Homebrew packages and apps. [`kitty.conf`](kitty.conf)
provides macOS terminal settings; [`.vim/settings/theme-overlay.vim`](.vim/settings/theme-overlay.vim)
is the macOS Vim theme overlay (stock Mocha); `launchd/` holds the plugin update
schedule and `ai-context/` holds machine guidance.
